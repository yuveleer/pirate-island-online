# Пиратский остров — онлайн

Это готовый к размещению серверный прототип, не уже опубликованный сайт.

## Публикация на Render через GitHub
1. Распакуйте архив. Создайте репозиторий GitHub и загрузите содержимое папки проекта в корень репозитория. В корне должны лежать package.json, server.js, game.js, render.yaml; папки public и test сохраняйте.
2. В Render выберите New → Web Service, подключите репозиторий.
3. Runtime: Node. Build Command: npm install. Start Command: npm start. Health Check Path: /health. Запускайте один экземпляр сервиса, не Static Site.
4. Выберите подходящий тариф (в конфигурации Blueprint указан free; его доступность, ограничения и стоимость проверяйте в интерфейсе платформы).
5. После успешного запуска откройте выданный Render HTTPS-адрес на iPhone.
6. Нажмите «Создать комнату» → «Пригласить друга». Друг открывает ссылку и нажимает «Присоединиться». Хозяин играет красными, друг синими.

Альтернатива: New → Blueprint с этим репозиторием использует render.yaml. Это может создать платный ресурс, если вы измените план: проверяйте параметры до подтверждения.

Документация размещения: https://render.com/docs/deploy-node-express-app

## Локальная проверка на компьютере
Нужен Node.js 20 или новее. В папке проекта:

npm test
npm start

Откройте http://localhost:3000. Создайте комнату. В другом браузере или приватном окне откройте приглашение и присоединитесь как второй игрок. Две обычные вкладки одного браузера используют один ключ игрока и не заменяют двух игроков.

Для игры через интернет адрес localhost НЕ подходит: разместите сервер публично. Для iPhone открывайте публичный HTTPS-адрес, не HTML-файл из архива.

## Реализовано
- Комнаты-приглашения на двух игроков.
- Сервер проверяет очередь, правила, номер ревизии и право игрока.
- Закрытые клетки не раскрываются в передаваемом клиенту состоянии.
- Обновления через Server-Sent Events, команды через HTTP POST.
- Повторное соединение после разрыва, ключ игрока сохраняется локально.
- Анимация перемещения, открытия клеток, частиц и счёта, мобильная вёрстка с safe-area.
- Авторские дополнения: пушки, лошади, лабиринты, ром, капитаны.

## Важные ограничения
- Комнаты в оперативной памяти. Перезапуск/сон/переразвёртывание процесса уничтожают текущие комнаты. Восстановление связи работает только пока сервер и комната живы. Для постоянных партий нужна база данных.
- Только один серверный экземпляр; при масштабировании нужен общий state/pubsub.
- Неактивные комнаты без соединений удаляются спустя 24 часа. Лимит — 300 комнат.
- Ссылка приглашения даёт возможность занять второе место: отправляйте её только другу. Ключ игрока в ссылку приглашения не входит.
- Для возврата нужен тот же браузер и сохранённый localStorage. При очистке данных места нельзя восстановить автоматически.
- Простой прототип для друзей, не продакшен-сервис: нет аккаунтов, базы, защиты от DDoS, наблюдателей и смены хозяина. Базовый лимит создания комнат не заменяет инфраструктурную защиту.
- Логи обратного прокси могут содержать токен SSE из query string. Не предоставляйте посторонним доступ к логам; для публичного продукта замените эту схему защищённой сессией.
- Реальные iPhone и публичный хостинг в этой среде не проверялись.

## Правила
Смотрите встроенную справку на сайте. Это авторская упрощённая версия, не точная реализация официального «Шакала». Перед каждой новой игрой создавайте новую комнату.
